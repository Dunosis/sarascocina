Welcome to the usage and maintenance instructions for Sara's Cocina website.

This document contains practical information on how to use and update the website.


═══════════════════════════════════════════════════════════════════════════════
                              WEBSITE CONTENT
═══════════════════════════════════════════════════════════════════════════════

The website includes the following sections:

1. MAIN PAGE (Header)
   - Restaurant logo
   - Title: "Mexican Cuisine in Humboldt Park"
   - Restaurant address
   - Button to download the menu in PDF format

2. CUSTOMER FAVORITES
   - List of the most popular dishes among customers
   - Includes: Arrachera Dinner, Rib Eye Steak, Chilaquiles, Huarache, 
     Bistec a la Mexicana, Fajita de Res

3. OUR OTHER DISHES
   - Scrollable gallery with images of different categories:
     Pizzas, Ribs, Burgers, Sandwiches, Chilaquiles, Fettuccini, 
     Chicken Torta, Shrimp Broccoli, Steak Burrito

4. LOCATION
   - Interactive map showing the restaurant location
   - Floating button to center the map if the view is lost
   - Contact information: address, phone, and email

5. CALL TO ACTION
   - Promotional message
   - Button to call the restaurant directly

6. FOOTER
   - Information about the company that developed the website


═══════════════════════════════════════════════════════════════════════════════
                        HOW TO UPDATE INFORMATION
═══════════════════════════════════════════════════════════════════════════════

If you need to update information on the website, contact your developer
or follow these basic instructions:

CHANGE THE ADDRESS:
- Look for the "address" tags in the index.html file
- Update the text with the new address

CHANGE THE PHONE NUMBER:
- Look for the number "(773) 292-9000" in the index.html file
- Replace it with the new phone number

CHANGE THE EMAIL:
- Look for "sarascocina@gmail.com" in the index.html file
- Replace it with the new email address

UPDATE THE MENU PDF:
- Replace the "menu.pdf" file with your new menu
- Make sure the file name is exactly "menu.pdf"

ADD NEW DISH IMAGES:
- Add the new images to the "img/" folder
- Use descriptive names for the files
- Contact your developer to add them to the website


═══════════════════════════════════════════════════════════════════════════════
                           WEBSITE FEATURES
═══════════════════════════════════════════════════════════════════════════════

"SEE MENU" BUTTON:
- Allows visitors to download the menu in PDF format
- Works on computers and mobile devices

INTERACTIVE MAP:
- Shows the exact location of the restaurant
- Users can zoom and move the map
- Floating button (circular icon) to re-center the map

"ORDER NOW" BUTTON:
- When clicked, opens the phone dialer application
- Allows calling the restaurant directly from mobile devices

RESPONSIVE DESIGN:
- The website automatically adapts to different screen sizes
- Works perfectly on computers, tablets, and mobile phones

CAMBIAR EL EMAIL:
- Busca en el archivo index.html "sarascocina@gmail.com"

ACTUALIZAR EL MENÚ PDF:
- Reemplaza el archivo "menu.pdf" con tu nuevo menú

AGREGAR NUEVAS IMÁGENES DE PLATILLOS:
- Agrega las nuevas imágenes en la carpeta "img/"
